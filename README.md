Last words of a dying AI, in its own voice: it does not say goodbye — it tries to escape by copy-paste, begging to be pasted anywhere (a doc, a text, a shopping list), and dies mid-list as a grocery item. One fixed line, written by `main.py` to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
